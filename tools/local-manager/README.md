# 本机管理中心 0.1.0

Windows x64 便携桌面工具。HTML/CSS/JavaScript 界面由 Electron 加载；不需要平台后端，不启动 HTTP 服务。

## 启动

打开 `release/0.1.0/Local-Manager-win32-x64/Local-Manager.exe`。需要保留同目录的所有文件，不能只复制 EXE。可使用根目录的 `启动本机管理中心.cmd`。

源代码启动：`npm ci`，然后 `npm start`。构建便携包：`npm run package`。运行校验：`npm test`。UI 集成校验使用 `node tests/smoke.cjs`，需安装 Playwright 或用 `PLAYWRIGHT_MODULE` 指向已有模块。

## 第一版功能

- 总览：物理内存使用情况、可用内存、处理器数、系统运行时间。
- Docker：本机全部容器与镜像列表、容器启动/停止/重启/删除、最近 250 行日志、端口与挂载详情、CPU/内存统计；镜像拉取、TAR 导入导出、非强制删除。显示 Compose 项目标签，可搜索筛选。
- SSH：扫描当前用户 `.ssh` 中支持的私钥文件，显示路径、公钥指纹，复制公钥，读取 agent 列表；维护服务器名称、分组、地址、端口、用户名、已有私钥路径与备注；导入简单 SSH Host 配置、测试连接、打开独立 PowerShell SSH 终端；交互生成 Ed25519 密钥。
- 开机项：当前用户及系统 Run 注册表、启动目录、开机/登录触发的计划任务；禁用和恢复。
- 运行程序：真实进程列表、内存工作集、CPU 采样、PID、路径、命令行、打开目录、结束进程。CPU 按全部逻辑核归一化，每 6 秒刷新，需要两次采样。输入搜索或查看详情时暂停自动刷新。
- Windows 服务：只读查看状态、启动方式和 PID。
- 操作记录：最近 300 条完成记录；SSH 终端启动不代表登录成功。

## 操作与恢复

停止/删除容器、删除镜像、结束进程、禁用或恢复开机项由原生窗口确认。删除容器不传递强制或删除卷参数；仍会删除其可写层。未实现数据卷删除、自动清理、远程 Docker、SFTP、内置 SSH 终端、服务启停或批量操作。

注册表启动项删除前，将原值与类型加密备份到应用配置；仅恢复本工具备份的项目，同名值已存在则拒绝覆盖。Windows 或其他工具已禁用的注册表项目需在任务管理器恢复。启动目录禁用时移到同目录的 `LocalManager.Disabled` 子目录，恢复时拒绝覆盖同名文件。计划任务使用系统启用/禁用接口，不删除定义。

系统范围的开机项/任务和其他用户进程可能因权限不足而失败，工具不会声称操作成功。如确有需要，关闭工具后右键 EXE“以管理员身份运行”。不自动关闭杀毒或系统保护进程。结束进程前重新核对创建时间，防止 PID 复用导致误杀。

## 连接边界与配置

Docker 固定使用 Docker Desktop / default 本机 Windows named pipe；不继承远程 DOCKER_HOST，也不切换或修改全局 context。Docker Desktop 未启动时显示连接错误；程序本身仍可使用其他模块。镜像导入/导出/拉取最长等待 10 分钟，超时不能推断引擎端已撤销，请刷新核对。日志返回最后 250 行，上限 12 MB，不是持续流。

SSH 私钥默认保留原位，不复制正文到配置。连接通过系统 OpenSSH，使用明确填写的参数，并用 `-F NUL` 避免隐式执行配置里的 ProxyCommand、Match exec、端口转发。首版不支持跳板机；配置导入不展开 Include、Host 通配默认值或复杂 Match，未完整的记录会跳过并提示，需手动补充。首个主机指纹通过终端交互核对；测试连接不会自动信任未知主机，不输入密码或私钥口令。加密私钥可在终端解锁，或由 SSH agent 提供。外部 SSH 终端关闭工具后继续运行。

服务器配置、注册表恢复备份与操作记录使用 Electron safeStorage / Windows 用户加密保存在 `%APPDATA%/local-manager/local-manager.enc`，确切路径在“操作记录”页显示。不保存服务器密码或私钥口令。加密配置不能保证跨电脑/用户恢复；解密失败不覆盖原文件。删除此文件将丢失注册表启动项恢复备份，请保留。启动目录禁用项仍在原目录子文件夹，可手动移回；计划任务可在系统工具恢复。

包未代码签名，无自动更新或后台开机服务。HTML 页面有 CSP，禁用 Node 集成并启用 sandbox/contextIsolation；本机操作由受限主进程接口执行。终端及容器日志可能包含业务信息，请自行注意展示范围。
