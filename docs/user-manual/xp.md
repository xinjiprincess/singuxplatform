# 跨平台传递

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

## 1\. 智能体的导入和导出

### 1.1 导出智能体

以待办助理为例，智能体中包含有插件、工作流（包含工作表操作）、MCP、知识库和页面等组件。 发布后，回到智能体开发页面，在点击智能体卡片右下角的菜单按钮，在弹出的菜单中点击“导出配置”按钮导出智能体。 导出的智能体会保存为`.agent`文件。

### 1.2 导入智能体

导入智能体时，需要先在智能体开发页面点击“导入配置”按钮，选择需要导入的智能体文件即可导入。

> 注意：
> 
> 1.  插件、工作流、MCP、知识库、数据表和页面等组件只有在智能体开发者**完全拥有这些组件**，导出智能体才会将这些组件一起导出，否则在导入时，这些组件会丢失。如下图所示，导入智能体时，MCP、插件和知识库丢失。
> 2.  **数据表**和**知识库**在导出时，只会导出数据表的结构和知识库的配置，不会导出数据表和知识库中的数据。

## 2\. 应用导出和导入

### 2.1 导出应用

在**应用开发页面**右侧的菜单按钮中找到“导出项目”选项，点击即可直接导出整个项目。

> 注意：和**智能体**一样，**应用**在导出时，应用加载的插件和工作流，如果包含有开发者无所有权的组件，不会随项目导出，数据表和知识库不会导出数据数据不会导出。

### 2.2 导入应用

导入应用时，点击**应用开发页面**右侧的创建按钮，在弹出的下拉菜单中选择**导入项目**，选择需要导入的项目`.zip`文件即可。
