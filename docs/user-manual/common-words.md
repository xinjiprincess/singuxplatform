## 参数与变量

-   `参数`用于传递动态数据，用于工作流、插件进行数据传入。
    
-   `变量`用于存储动态数据，在工作流中作用域覆盖后续的所有流程节点，与**参数**基本一样，一般生命周期比**参数**稍长，它即可用于传递数据，也可用于临时存储数据，比如定义一个“喜欢的城市”变量，不同用户的偏好可能不同，那么对后续的业务逻辑影响也可能不一样。在智能体编排中进行设置，可在智能体提示词、工作流节点输入参数时引用，如果变量需要用户输入，则会在会话页面展示。
    
    不用特别去理解二者的差异，都是用于传递动态数据。
    
-   `数组`就像是一个有很多小格子的盒子，每个格子可以放一样东西（比如数字、文字或其他数据）。你可以给每个格子编号（比如第1个格子、第2个格子……），这样就能方便地找到或修改某个格子里的东西。 举个例子： 如果你有一个数组叫“水果”，可以这样放东西：
    
    -   第1个格子放“苹果”
    -   第2个格子放“香蕉”
    -   第3个格子放“橙子”
    
    JSON格式的表示形式：
    
    ```json
      [ "苹果", "香蕉", "橙子" ]
    ```
