# 工作空间介绍

> 更新：2026-10-04。空间权限与系统角色分别管理；不能因有空间页面而推断全部后端资源隔离已经验收。

> 智能体平台 · 基础篇 认识 智能体平台 的资源组织单元——工作空间

**工作空间是资源组织的基础单元**，不同空间内的资源和数据相互隔离。你创建的所有智能体、工作流、插件、知识库、数据表、模型，都归属于某个空间。理解工作空间，是开始智能体开发的第一步。

* * *

## 一、空间类型：个人空间与团队空间

智能体平台 提供两种空间形态，满足个人开发与团队协作两类场景。

### 个人空间

每位用户注册后**自动获得**一个独享开发环境，支持智能体开发设计、资源调试与私有化部署。空间内的模型、知识库及工作流资源受**隐私保护机制隔离**，其他用户无法访问。

### 团队空间

支持创建**多人在线协作空间**，通过精细化权限管理系统（**创建人 / 管理员 / 成员** 三种角色），实现 AI 组件共享与版本协同开发——适合团队一起共建、共用一套智能体资产。

| 对比项 | 个人空间 | 团队空间 |
| --- | --- | --- |
| 获取方式 | 注册即自动拥有 | 手动创建 |
| 适用场景 | 个人开发、学习、私有部署 | 多人协作、部门共建、班级教学 |
| 协作能力 | 单用户独享 | 多成员协作，角色权限管理 |
| 资源隔离 | 隐私保护机制隔离 | 空间内共享、跨空间隔离 |

## 三、成员与设置

团队空间创建后，可以通过「成员与设置」管理**空间成员**与**空间设置**——进入入口后，页面包含「成员管理」与「空间设置」两个标签页：

### 3.1 成员管理

团队空间下可以**添加空间成员**，一起协作开发智能体。点击「添加成员」，通过**手机号、邮箱或用户名检索**成员：

> 注意：只有检索正确的信息才会显示用户，**输入需要回车Enter才会开始检索成员**

勾选成员后，为成员**设置角色**（管理员 / 成员），即可完成添加。其中**管理员可以添加、删除成员**，协助创建人管理团队空间：

### 3.2 空间设置

**空间设置仅创建人（团队空间所有者）拥有操作权限**，包含**转让空间、删除空间、开发者功能、接受来自外部空间的发布**四项能力：

-   **转让空间**：将空间所有权转移给其他成员，转让后原创建人将成为管理员身份。
-   **删除空间**：空间删除后**所有资产将无法恢复**，请谨慎操作。
-   **开发者功能**：仅**创建人**可关闭。关闭后，普通成员将无法使用「智能体开发」和「组件资源」，但**管理员仍然可以使用**；主要用于发布的智能体**仅供团队成员使用**的场景（团队成员无需知道开发细节）。
-   **接受来自外部空间的发布**：打开后，拥有该空间权限的用户在其他空间完成开发的智能体、插件、工作流，可以**发布到该空间的广场**上。

## 四、空间功能介绍

空间内围绕**开发、资源、协作与运营**提供一系列功能模块，主要包括：**智能体开发、网页应用开发、组件资源、技能管理、MCP管理、资源定价、IM机器人、任务中心、日志查询、空间广场**。

### 4.1 智能体开发

管理展示在空间下创建的**所有智能体**——问答型、通用型、AgentFlow、AgentGroup 都在这里统一管理。

### 4.2 网页应用开发

支持在空间内**开发和管理网页应用**，将智能体能力封装为可直接访问的网页应用。

进入开发页面后，可以在**开发页**中通过对话生成、配置并预览网页应用：

### 4.3 组件资源

统一沉淀开发所需的**组件资源**——插件、工作流、知识库、数据表、模型，供空间内所有智能体调用。

#### 4.3.1 插件

插件是平台的**扩展能力组件**，可以为智能体挂载额外的工具与服务能力，是开发智能体时最常用的能力来源之一。

#### 4.3.2 工作流

工作流将多个执行步骤**编排为自动化流程**，供智能体、网页应用按流程调用执行，实现复杂任务的自动化处理。

#### 4.3.3 知识库

知识库是智能体的**知识增强底座**，支持导入文档数据，为智能体提供 RAG 检索增强问答能力。

#### 4.3.4 数据表

数据表提供**结构化数据的存储与管理**能力，智能体可以直接读写空间内的数据表资源。

#### 4.3.5 模型管理

模型管理统一维护空间内可用的**模型资源**，包括模型的名称、版本、类型与状态等信息，是智能体调用底层大模型能力的基础。

需要接入新模型时，点击「新增模型」，通过**模型类型、供应商、模型名称**等信息完成配置：

### 4.4 技能管理

管理空间内的**技能**资源，统一维护技能的创建、配置与使用。

### 4.5 MCP管理

管理接入的 **MCP 服务**，同时支持将在平台开发的工作流、插件、知识库、数据表**发布导出为 MCP 服务**，实现能力对外输出与复用。

### 4.6 资源定价

为空间内的**模型、工具、技能**等资源设置定价，支撑资源对外共享与商业化使用。

### 4.7 IM机器人

提供 **IM（即时通讯）机器人**能力，将智能体接入即时通讯场景，在对话中直接提供服务。

### 4.8 任务中心

支持**指定智能体定时完成用户要求的任务**——用户布置任务并设定执行时间，智能体会按计划自动执行，完成后可在任务中心查看任务的执行情况与记录。

### 4.9 日志查询

提供空间内的**操作日志查询**能力，记录空间内各项操作行为，便于审计与回溯。

### 4.10 空间广场

空间广场以空间作为隔离范围形成一个**圈子**，让同部门、同班级、同兴趣的用户将开发完成的**工作流、插件、智能体**进行分享使用，实现空间内资源共享。

## 五、总结

-   **工作空间是资源组织的基础单元**：智能体、工作流、插件、知识库、数据表、模型全部归属于空间，跨空间数据隔离。
-   **个人空间**：注册即得，独享开发环境，适合个人开发与私有化部署。
-   **团队空间**：多人协作、角色权限（创建人/管理员/成员）、组件共享，适合团队共建。
-   **成员与设置**：管理空间成员（添加成员、角色分配）与空间设置（转让、删除、开发者功能等），是空间协作与治理的核心。
-   **空间功能模块**：智能体开发、网页应用开发、组件资源、技能管理、MCP管理、资源定价、IM机器人、任务中心、日志查询、空间广场，覆盖开发、资源、协作与运营全流程。
