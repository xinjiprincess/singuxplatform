# 系统配置用户操作手册

> 更新：2026-10-04。示例服务地址不可解析，必须填写真实配置。品牌和自定义域名仍受套餐与实施开关约束。

## 一、概述

系统配置是智能体平台的管理后台核心功能之一，用于管理员对整个站点的基础信息、模型设置和智能体配置进行统一管理。本手册将详细介绍各项配置的功能及使用方法。

## 二、访问入口

1.  登录智能体平台管理系统
2.  在左侧导航栏中选择 **系统管理** > **系统配置**
3.  进入系统配置页面

## 四、保存配置

完成各项配置后，点击页面底部的 **保 存** 按钮即可保存所有更改。

> **注意**：部分配置保存后会立即生效，部分配置可能需要重启相关服务或重新登录后才能生效。

## 五、常见问题

### Q1：图片上传失败怎么办？

A：请确保上传的图片格式正确（Logo建议使用PNG/JPG，Favicon需使用.ico格式），且文件大小符合系统限制。

### Q2：如何获取阿里云短信和验证码服务的AccessKey？

A：需要登录阿里云控制台，在访问控制(RAM)中创建AccessKey，并确保该AccessKey具有短信服务权限。

### Q3：修改默认模型后已创建的智能体是否会受影响？

A：不会。默认模型设置仅影响新建智能体时的默认选项，已创建的智能体保持原有的模型配置。详见[智能体编排指南](agent-design.md)。

### Q4：安全检查提示词如何编写？

A：提示词应包含安全检测的范围、目标和限制条件，确保能够识别潜在的恶意代码行为。可参考系统默认的提示词模板进行修改。

### Q5：沙箱配置中的各项参数代表什么？

A：

-   `serverAgentUrl`：沙箱Agent服务的通信地址
-   `serverVncUrl`：沙箱VNC远程桌面访问地址
-   `serverFileUrl`：沙箱文件服务地址
-   `maxUsers`：该沙箱服务器最大支持的用户数
-   `perUserMemoryGB`：每个用户分配的内存（GB）
-   `perUserCpuCores`：每个用户分配的CPU核心数

> 详细配置说明请参考：[智能体电脑部署指南](agent-computer-deploy.md)

## 六、注意事项

1.  **敏感信息保护**：SMTP密码、API密钥等敏感信息请妥善保管，不要泄露给无关人员
2.  **配置备份**：重要配置修改前建议先记录原有配置，以便需要时恢复
3.  **模型资源**：选择默认模型时需考虑成本和性能的平衡
4.  **审核机制**：建议在生产环境中开启内容审核，确保平台内容质量
5.  **安全检查**：开启代码插件安全检查可以有效防范潜在的安全风险
