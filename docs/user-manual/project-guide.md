# 项目操作指南

更新：2026-10-04。根据当前路由、服务接口、版本记录和运维文档整理。源码有功能入口，不代表服务器已经上线该功能。

## 1. 项目现状

平台名称为 Singu X，主入口为 https://www.ciyuancenter.cc ，登录路径 /login。前端 package.json 版本为 1.1.10；Windows 人员导入工具当前 package.json 为 v0.1.5。工具 README 顶部保留 v0.1.1 历史说明，最新规则以末尾 0.1.3—0.1.5 更新为准。

线上继续单租户，仅更新验证过的修复和用户导入兼容。普通用户不需要选择企业；本地存在企业页面不能视为启用企业功能。完整多企业隔离、自动客户域名证书和企业支付尚未完成验收。

已有空间、资源、智能体、网页开发、任务、日志与系统管理页面。真实模型、MCP、沙箱、文件、网页生成和发布依赖配套服务。页面能打开、镜像能构建不代表链路可用。

微信支付和支付宝只预留。个人订阅积分、企业额度、真实收款及模型供应商账单分别管理，不能用额度配置或用量展示证明已完成扣款结算。

## 2. 登录与个人设置

### 2.1 登录步骤

1. 打开登录页，核对域名与站点信息。
2. 输入管理员分配的用户名和密码；工号/学号保留原始前导零。
3. 当前环境如要求验证码，完成提示后再提交，避免重复点击。
4. 登录后进入首页或授权空间。

页面保留验证码相关流程，是否启用由服务器决定；不能描述为所有环境都支持自行注册。用户名密码是本项目主要登录方式。

当前工具新建账号默认学校代号拼接手机号作为初始密码，应及时修改；已有用户不重置。学校代号拼接学号作为用户名，保留学号前导零。历史 v0.1.1 纯学号/手机号任务保持历史规则；旧服务器纯数字用户名兼容需单独验证。

### 2.2 账号及退出

头像菜单提供个人信息、账号设置和退出。按权限修改昵称、联系方式与密码，共用电脑使用退出结束会话。登录失效、验证码失败、重名或无权限时保留时间和错误联系管理员，不修改浏览器 token、角色或资源 ID 绕过认证。

## 3. 空间与成员

空间组织智能体、插件、工作流、知识库、数据表、模型、技能和网页。个人空间用于个人资源，团队空间用于协作。系统角色、空间角色及资源授权分别管理。

- /space：空间列表。
- /space/:spaceId/develop：智能体开发。
- /space/:spaceId/team：成员与设置。
- /space/:spaceId/space-square：空间广场。

创建团队空间后填写名称说明，检索用户名、邮箱或手机号添加已有成员，按职责分配角色。能登录不代表有团队权限。转让、删除及关闭开发者功能按账号权限操作；删除前核对资源和数据影响并导出需要内容。

前端空间列表不能替代后端逐资源授权验证。详细步骤见 [工作空间](workspace.md)。

## 4. 准备资源

### 4.1 模型

系统模型管理及 /space/:spaceId/model-manage 维护模型。核对供应商、协议、模型 ID、Base URL、密钥、能力与状态。显示名可与供应商 ID 不同，调用 ID 必须准确。

先测试最小文本请求并确认正文，再用于智能体。知识库需要兼容向量模型。平台 API Key 与模型密钥不同。模型通常通过后端与模型代理调用，普通业务接口与代理端口不能混用。

Base URL 必须有协议，不使用示例 .invalid 域名。HTTP 200、usage 或 reasoning 不证明最终正文存在；空回复检查响应类型、工具调用、结束原因、requestId 和节点状态。

### 4.2 插件、工作流、MCP

插件封装函数，工作流编排步骤，MCP 接入外部工具。先配置输入、输出、凭据及权限，验证成功和失败样例后挂载。

插件/工作流入口为 /space/:spaceId/plugin-workflow，MCP 为 /space/:spaceId/mcp。不授予不必要宿主目录、Docker socket 或凭据。智能体调用工具不自动扩大服务权限。

### 4.3 知识库与数据表

入口 /space/:spaceId/knowledge-storage。知识库用于文档检索，数据表用于结构化记录。上传后核对解析、分段、索引与检索，再挂载。

问答测试覆盖有依据、无资料和易混淆问题，要求明确依据；模型自身回答不代表知识命中。数据表先定义类型和必填，再使用测试数据验证查询和更新，避免无条件批量修改。

### 4.4 技能及子智能体

技能入口 /space/:spaceId/skill-manage。导入前审核指令、脚本、资源、依赖、来源及许可。子智能体适合专门分工，支持情况依赖类型和执行环境。技能说明不等同权限授权。

## 5. 智能体创建、调试、发布

### 5.1 第一个问答型

1. 智能体开发中创建问答型，填写名称、介绍和图标。
2. 提示词说明对象、目标、资料范围、格式与未知问题处理。
3. 选择已验证模型，设置历史轮数、输出长度和生成参数。
4. 挂载需要的知识库、表格、插件、工作流或 MCP，未挂载不会自动读取资源。
5. 测试正常、歧义、无资料及工具失败问题。
6. 保存并按空间允许方式发布，以普通成员验证访问和资源权限。

编辑路由 /space/:spaceId/agent/:agentId。见 [问答型](qa-agent.md) 和 [入门教程](first-agent.md)。

### 5.2 通用型

通用型处理多步骤、文件和代码任务，需独立执行环境。管理员确认沙箱可用后配置模型、技能和工具。先跑简单可回收任务，验证状态、文件、取消和释放，再跑长任务。

验收不只看回复，还检查产物可打开、满足要求及环境回收。见 [通用型](general-agent.md)、[子智能体](subagents.md) 和 [沙箱](sandbox-management.md)。容器健康不证明真实执行链路。

### 5.3 工作流

定义开始输入、处理节点、条件与结束输出；变量引用正确节点及作用域，区分列表和单值。先测节点再测全流程，覆盖空输入、超时、分支未命中、外部错误及重复触发。

路由 /space/:spaceId/workflow/:workflowId。日志核对节点输入输出、耗时和状态，不只看全局成功。类型及编排说明见 [编排总览](agent-orchestration.md)。

### 5.4 对话与分享

首页会话 /home/chat/:id/:agentId，独立应用 /app/:agentId，独立会话 /app/chat/:agentId/:id。主页快捷按钮可连接已配置智能体。

临时分享和 iframe 仍需服务端认证，URL 参数不是权限，不在链接传长期密钥。嵌入页按目标环境确认跨域及浏览器策略。

## 6. 网页开发

空间列表 /space/:spaceId/page-develop，IDE /space/:spaceId/app-dev/:projectId，设计页 /space/:spaceId/app-dev-design/:projectId。

1. 创建项目，描述内容、交互与数据来源。
2. 聊天生成或修改，观察思考、正文和工具状态。
3. 文件树选择文件，在 Monaco 编辑并确认保存结果。
4. 核对开发服务器，预览导航、按钮、表单、响应式和错误提示。
5. 联调鉴权及后台接口后再发布。

文件管理、开发服务器、聊天与 SSE 管理器共同运行。断网、重连、取消和晚到响应需要验证。预览失败先查项目、开发服务、文件服务及网关，避免重复创建。

模拟模式不证明真实上传、保存和发布。见 [网页应用](page-develop.md) 和 [运行恢复记录](../runtime-recovery-and-updates.md)。

## 7. IM、任务、日志与迁移

IM 入口 /space/:spaceId/im-channel。按渠道设置机器人、标识、凭据、权限、回调和智能体，测试收发、签名和重试。渠道权限与空间授权分别配置。

任务入口 /space/:spaceId/task-center。填写内容、智能体、时间及重复周期，核对时区、启停、下次执行与通知目标；首次运行检查日志及产物。未配置渠道时不能承诺自动通知外部联系人。

智能体日志 /space/:spaceId/:agentId/log，组件日志 /space/:spaceId/library-log，系统运行日志由管理员使用。收集时间、空间/项目/智能体 ID、requestId/tid、输入输出、耗时与错误；分享前脱敏密钥、口令和个人数据。HTTP 成功也要检查业务 code。

迁移先导出智能体，再核对插件、工作流、MCP、知识库、模型及页面依赖。导入目标空间后补齐真实配置并测试，资源 ID、发布链接和凭据不保证跨环境有效。见 [迁移](xp.md)。

## 8. 系统管理

管理员按权限维护用户、用户组、角色、菜单、内容、模型、沙箱和站点。直接输入管理地址不增加权限。系统配置包含站点、登录、通知、模型与节点，密钥仅在受控接口配置，不出现在公开品牌配置或文档截图。

项目已清理推广页脚，前端过滤服务端文档菜单；整理版为离线 Markdown，没有自动新增网页入口。

### 8.1 Windows 批量用户导入

tools/user-manager 提供 Windows x64 便携版 v0.1.5，启动 release/0.1.5 目录程序，先退出旧版，保留 EXE 同目录全部文件。

1. 配置 HTTPS，选择单租户平台，不填 tenantId、不请求企业成员接口。
2. 添加具备用户管理权限的平台 API Key 并绑定环境，SSH 口令不能代替 Key。
3. 读取 xls、xlsx、csv 或递归目录，确认专用报名解析或普通列映射。
4. 输入稳定单位代号，预览工号/学号、用户名、手机号、邮箱及来源行。
5. 修复缺失、重复和冲突，保留学号前导零；原文件已丢的零不能恢复。
6. 核对地址、范围、Key、人数和口令规则，检查连接后确认导入。
7. 查看结果及失败项，口令导出单独确认，受控发放后及时删除明文。

当前默认账号为学校代号直接拼接学号/工号，密码为学校代号直接拼接手机号，不含加号和空格。例如 cdut000123、cdut13800138000；初始密码易猜，应及时修改。已有一致账号跳过，不改名、不重置；历史任务保持旧规则。

新任务默认 3 路并发，可配置 1—5 路，全局启动间隔至少 250ms，实际速度取决于服务器响应和限流。旧任务保持原串行速度。单账号字段错误或冲突不阻断其他账号；鉴权、限流、列表读取及本地保存错误仍暂停整批。

结果待核对可能是服务端已写入但响应丢失，不能直接重放新增。使用任务中心逐行核对，字段问题修正原表后再生成预览。未成功账号 Excel 不含密码，导出当前快照的失败、冲突、待核对及未提交项；含个人联系方式，受控保存。

默认 phone 与 email 都要求存在；目标服务确认单项可用后才调整，不能编造。响应混合租户仍停止。旧后端数字登录限制需先修复验证。

AI 只辅助字段映射，确认后仅发送表头，不上传名单或工作簿，不处理图片、PDF、Word 或 OCR。Windows 用户级加密存储密钥和任务，不明文回退；导出口令为明文。版本未签名、无自动更新。

见 [客户端说明](../../tools/user-manager/README.md)。

## 9. API 集成

管理员先授权接口，用户创建 Key 并设置用途、有效期和资源范围。平台 Key 与模型 Key 不混用。

会话常见顺序：创建取得 conversationId，发送请求，解析结果或 SSE，查询消息状态，需要时停止，再查询和读取产物文件。Authorization 使用接口约定的 Bearer 认证。

业务 code 为 0000 才按文档判成功；HTTP 200 不代替业务结果。示例 Key 为占位值，.invalid 域名不可解析。接口参考没有对生产执行新增、停用、更新或删除测试，旧约束与改造可能不同，先验证测试环境。

额度或 429 错误暂停限速，不轮换 Key 绕过限额。ticket 为临时认证，服务端验证，不作为长期分享口令。

## 10. 运维与排查

前端只在当前仓库构建，后端在指定独立工程构建，不覆盖已有品牌和登录修改。生产继续单租户；更新前核对基线、最小补丁、备份与隔离验收，不直接发带未验收多企业代码整包。

常见排查：

- 登录失败：域名、账号状态、验证码、数字用户名兼容。
- 无资源：成员、角色、空间及资源授权。
- 空回复：模型协议、标识、地址、代理、正文和结束原因。
- 工具错误：参数类型、凭据、连接、schema 及限额。
- 知识未命中：解析、分段、索引、向量模型及检索测试。
- 沙箱失败：调度、镜像、额度、文件及回收。
- 预览失败：保存、开发服务、网关与浏览器错误。
- 定时失败：时区、启停、执行时间、权限与日志。

验收覆盖登录、空间、模型正文、智能体、资源权限和退出；配套能力另外验证工具、文件、沙箱及发布。健康、单元测试和镜像构建只证明相应检查。

本批只生成文档，不更新服务器、不重启容器、不迁移数据、不改菜单。
