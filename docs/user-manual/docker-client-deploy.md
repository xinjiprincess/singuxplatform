## Windows 用户管理工具

项目 tools/user-manager 提供 Windows x64 便携版 v0.1.5，用于读取表格、预览、核对和创建普通用户，不提供通用智能体桌面。

配置单租户 HTTPS 地址和平台 API Key，不填写企业 ID，不调用企业成员接口。见 [项目操作指南](project-guide.md) 及 [客户端说明](../../tools/user-manager/README.md)。

另行接入执行客户端需验证认证、协议、版本和隔离，不提供未实现的下载地址或默认账号。
