# 零代码生成客服智能体

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

## 第一步，准备产品信息

**[2025 年上半年 20 款最新手机产品盘点（演示示例）](2025%E5%B9%B4%E4%B8%8A%E5%8D%8A%E5%B9%B4%E6%96%B0%E6%89%8B%E6%9C%BA%E4%BA%A7%E5%93%81%E7%9B%98%E7%82%B9.md)**

> 需要根据情况提前准备好，如需要客服展示产品图片，需要在产品信息中提供图片链接，参考产品信息示例文档

## 第二步，将产品资料上传知识库

1.  找到**工作空间→组件库→组件→创建知识库**
2.  填写知识库**名称，描述**知识库内容（名称和描述需要尽量精准，大模型在调用时，会先根据名称和描述识别是否需要调用） **3\. 上传产品信息文档→自动分段与清洗**
3.  文档会自动进行构建和清洗，中间需要等待一些时间，**文件的内容越多清洗的时间会越长**，建议可以先去完成其他工作
4.  构建成功后会在此页面**显示文档内容****QA问答**显示对文档内容可能出现的问题进行预回答

## 第三步，创建智能体

1.  找到**工作空间→智能体开发→创建智能体**
2.  输入**智能体名称**和**智能体功能介绍**（这里的名称和介绍也请尽量和实现的功能相关，后续在自动生成提示词时会有一定影响）
3.  创建成功进入智能体**编辑界面**，输入**系统提示词**
4.  使用**AI自动生成**系统提示词
5.  点击**替换**即可将自动生成提示词填入“系统提示词”位置
6.  选择**AI模型**，有两种类型模型选择**会话模型**和**推理模型**（推理模型会展示推理过程，展示结果的过程速度稍慢）
7.  创建**工作流**
8.  **工作流节点**介绍
    -   **开始**节点 开始节点只添加一**个input**[变量](%E5%B8%B8%E7%94%A8%E8%AF%8D%E8%A7%A3%E9%87%8A.md)作为输入数据，类型为**字符串类型String**，描述为**用户提问**，勾选为**必须**
    -   **大模型**节点
    -   **循环**节点
        -   循环中每次使用大模型生成的多个词组中的**一个词**到知识库中去查找相关词语
    -   **结束**节点，输出循环节点中查找出来的所有数据
9.  **测试**工作流 **查看最终测试结果**

> 测试会暴露处工作流的各种问题，可以针对这些问题适当的调整各节点的设置

10.  **添加工作流**

## 第四步，创建数据表

> 这里创建两个数据表，一个是**手机产品地区销售名单**，用于为客户提供地区销售联系方式，一个是**客户咨询名单**，用于记录客户信息和需求

1.  准备资料，（这里模拟了一个销售名单）
2.  创建并导入**销售信息**到**数据表**（数据表**无需手动新增字段**，系统会自动识别每列列标题并转化为标准的字段名，方便用户上传）
3.  创建**客户信息表**并添加到智能体中
    1.  创建**开场白**（开场白的作用是用户最开始使用智能体时起提示作用）
    2.  添加开场白**预置问题**

## 第五步发布智能体

1.  点击右上角**发布**按钮
2.  填写**发布信息**
