# 智能体编排方式总览

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

> 智能体编排 · 导览篇 快速认识 智能体平台 四种智能体类型及其编排方式

智能体平台 提供四种智能体类型，各自**定位不同**：**问答型**轻量快答、**通用型**执行复杂任务、**AgentFlow** 以工作流编排多智能体协作、**AgentGroup** 以协作组实现多智能体分工。相应地，它们的**编排方式**也各不相同——开箱即用、配置驱动、画布拖拽、群组协同。本页做总览导览，每种类型的详细编排方式见对应详解文档。

* * *

## 四种智能体编排方式速览

| 类型 | 编排方式 | 一句话概括 | 详解文档 |
| --- | --- | --- | --- |
| **问答型** | 开箱即用 | 适合知识问答、智能客服等**快问快答**场景，轻量响应快；可挂工具，可配自定义页面（专属） | [问答型详解](qa-agent.md) |
| **通用型** | 配置驱动 | 分配**独立执行电脑**，适合开发/深度调研/数据分析等复杂任务 | 通用型详解 |
| **AgentFlow** | 画布拖拽 | 基于多智能体协作编排的**工作流**：任务拆解、分支决策、人工介入、结果评估 | AgentFlow详解 |
| **AgentGroup** | 群组协同 | 多智能体**协作组**：适合多个智能体分工协作的复杂任务场景 | AgentGroup详解 |

## 一、问答型智能体

**定位：快问快答。** 适合**知识问答、智能客服**等快问快答的场景——创建后即可对话，轻量、响应快、资源消耗低。

与通用型一样，问答型同样可以**挂载工具**（插件、MCP、工作流、知识库、数据表等），工具决定智能体的"本事"：只配模型与提示词，回答只能"大概差不多"；挂上知识库、数据表，回答才能有据可查。

问答型的**专属亮点是自定义页面组件**（通用型不支持）：可单独创建一个组件页面（如待办事项管理页面），**智能体可控制页面**（对话中按指令操作），**用户也可直接通过页面使用功能**，无需对话。

> 🔗 详细编排方式见《问答型智能体编排详解（v3）》

**问答型智能体编排界面不带界面****问答型智能体带组件页面**

* * *

## 二、通用型智能体

**定位：复杂任务执行者。** 创建后同样可以对话、可以挂载工具，它的特别之处在于——**为智能体分配独立的执行电脑**，能运行代码、执行复杂操作，适合**应用开发、深度调研、数据分析、演示文稿制作**等复杂任务场景；相应地**比较消耗内存资源，输出结果较慢**。

通过「配置」不断叠加能力：挂载技能（Skills）、配置子智能体（Subagents）委托任务、添加 Hook 回调、开启调用审批与版本管理等。注意：**通用型不支持配置自定义页面组件**（这是它与问答型的差异）。

> 🔗 详细编排方式见《通用型智能体编排详解（v2）》

* * *

## 三、AgentFlow（流程型）

**定位：基于多智能体协作编排的工作流。**

在编排画布上把「路由决策、智能体、工作流、询问用户」等节点**拖拽、连线**，搭建可视化工作流，流程按连线方向依次执行，实现多智能体协同编排。适合**复杂任务拆解**（把大任务拆成节点步骤）、**分支决策**（路由节点按条件判断走向）、**人工介入**（询问用户节点暂停等待人工输入）、**结果评估**等场景。

> 🔗 详细编排方式见《AgentFlow编排详解》

* * *

## 四、AgentGroup（群组型）

**定位：多智能体协作组。**

将多个智能体组成一个「群组」共同工作，在群组内做**角色分工**与**任务分配**，任务经路由分派给群组成员执行，最终**汇总结果**。适合需要多个智能体分工协作的复杂任务场景。

> 🔗 详细编排方式见《AgentGroup编排详解》

* * *

## 如何选择

-   **要快问快答、轻量响应（知识问答 / 智能客服）** → 问答型（开箱即用）
-   **要跑复杂任务（开发 / 深度调研 / 数据分析 / 演示文稿）** → 通用型（配置驱动）
-   **要拆解复杂任务、做分支决策、支持人工介入与结果评估** → AgentFlow（画布编排）
-   **要多个智能体分工协作完成复杂任务** → AgentGroup（群组协同）
