## 系统概述

智能体平台的权限管理模块是一个功能完善的权限控制系统，支持以下核心功能：

-   **角色管理**：创建和管理系统角色，为角色分配菜单权限和数据权限
-   **用户组管理**：创建用户组，批量管理用户权限
-   **菜单管理**：管理系统菜单结构，控制菜单显示和访问
-   **权限资源管理**：管理系统权限资源，包括模块、按钮等资源的权限控制

## 角色管理

角色管理是权限管理的核心模块，用于定义系统角色并分配相应的权限。

### 查看角色列表

1.  进入「角色管理」页面
2.  页面展示所有角色列表，包括：
    -   **排序**：角色显示顺序
    -   **角色名称**：角色显示名称
    -   **编码**：角色唯一标识
    -   **描述**：角色功能说明
    -   **状态**：启用/禁用状态
    -   **操作**：管理按钮

### 查询角色

1.  在页面顶部的查询区域：
    -   **角色名称**：输入角色名称进行搜索
    -   **编码**：输入角色编码进行搜索
2.  点击「查询」按钮执行搜索
3.  点击「重置」按钮清空查询条件

### 新增角色

1.  点击页面右上角「新增角色」按钮
    
2.  在弹出的对话框中填写以下信息：
    
    | 字段 | 说明 | 限制 |
    | --- | --- | --- |
    | 角色名称 | 角色显示名称 | 必填，最多50字符 |
    | 来源 | 角色来源 | 系统自动生成，不可修改 |
    | 排序 | 显示顺序 | 1-10000 |
    | 状态 | 启用/禁用 | 开关控制 |
    | 描述 | 角色说明 | 最多500字符 |
    
3.  填写完成后点击「创建」按钮
    
4.  系统自动生成角色编码（拼音格式）
    

### 编辑角色

1.  在角色列表中找到目标角色
2.  点击操作列的「编辑」按钮（通过更多操作菜单）
3.  修改角色信息
4.  点击「确定」保存修改

### 启用/禁用角色

1.  在角色列表中找到目标角色
2.  点击操作列的启用/禁用开关
3.  禁用的角色将无法被用户使用

### 绑定用户

为角色关联具体的用户账户。

1.  在角色列表中找到目标角色
2.  点击「绑定用户」按钮
3.  在弹出的对话框中：
    -   在搜索框中输入用户名、邮箱或手机号码
    -   按回车键搜索用户
    -   选择要绑定的用户
    -   查看已选成员列表
4.  完成后关闭对话框

### 配置菜单权限

控制角色可以访问的系统菜单。

1.  在角色列表中找到目标角色
2.  点击「菜单权限」按钮
3.  在弹出的对话框中：
    -   勾选角色可以访问的菜单项
    -   支持多级菜单选择
    -   父级菜单选中会自动选中子菜单
4.  点击「确定」保存配置

**系统菜单示例：**

-   新建会话
-   主页
-   工作空间
-   广场
-   生态市场
-   系统管理
-   文档
-   通知
-   我的电脑

### 配置数据权限

控制角色可以访问的数据资源。

1.  在角色列表中找到目标角色
2.  点击「数据权限」按钮
3.  在弹出的对话框中，有以下几个标签页：

#### 模型权限

-   显示可用的AI模型列表（如：qwen3.5-plus、qwen3.5-plus-anthropic）
-   点击「添加」按钮将模型添加到已选列表
-   已选模型会显示在下方列表中

#### 智能体权限

-   在搜索框中输入关键词搜索智能体
-   点击「添加」按钮将智能体添加到已选列表
-   查看已选智能体列表

#### 网页应用权限

-   管理角色可以访问的网页应用
-   添加/移除网页应用权限

#### 数据配额

配置角色的资源使用限制和配额。

**配额设置项：**

| 配额项 | 说明 | 默认值 |
| --- | --- | --- |
| 每日token限制 | 角色用户每日可使用的token总数 | \-1（无限制） |
| 可创建工作空间数量 | 角色用户可创建的工作空间数量上限 | \-1（无限制） |
| 可创建智能体数量 | 角色用户可创建的智能体数量上限 | \-1（无限制） |
| 可创建网页应用数量 | 角色用户可创建的网页应用数量上限 | \-1（无限制） |
| 可创建知识库数量 | 角色用户可创建的知识库数量上限 | \-1（无限制） |
| 知识库存储空间上限 (GB) | 知识库占用的存储空间上限 | \-1（无限制） |
| 可创建数据表数量 | 角色用户可创建的数据表数量上限 | \-1（无限制） |
| 可创建定时任务数量 | 角色用户可创建的定时任务数量上限 | \-1（无限制） |
| 智能体电脑内存(GB) | 智能体运行时可使用的内存大小 | 4 GB |
| 智能体电脑 CPU 核心数 | 智能体运行时可使用的CPU核心数 | 2 核 |
| 通用智能体每天对话次数限制 | 每日与通用智能体的对话次数上限 | \-1（无限制） |
| 网页应用开发每天对话次数 | 网页应用开发每日对话次数上限 | \-1（无限制） |

**说明：**

-   设置为 `-1` 表示无限制
-   智能体电脑内存和CPU核心数会影响智能体的运行性能
-   配额设置可以帮助控制系统资源的使用

4.  完成后点击「确定」保存

### 删除角色

1.  在角色列表中找到目标角色
2.  点击操作列的「更多」按钮（...）
3.  选择「删除」选项
4.  确认删除操作

**注意：** 删除角色前请确保没有用户绑定该角色。

## 用户组管理

用户组用于批量管理具有相同权限需求的用户。

### 查看用户组列表

1.  进入「用户组管理」页面
2.  页面展示所有用户组，包括：
    -   **排序**：用户组显示顺序
    -   **用户组名称**：用户组显示名称
    -   **编码**：用户组唯一标识
    -   **描述**：用户组说明
    -   **状态**：启用/禁用状态
    -   **操作**：管理按钮

### 查询用户组

1.  在页面顶部的查询区域：
    -   **用户组名称**：输入用户组名称搜索
    -   **编码**：输入编码搜索
2.  点击「查询」按钮
3.  点击「重置」按钮清空条件

### 新增用户组

1.  点击页面右上角「新增用户组」按钮
2.  填写用户组信息（与角色管理类似）
3.  点击「创建」完成

### 用户组操作

用户组的操作与角色管理基本相同，包括：

-   **绑定用户**：将用户添加到用户组
-   **菜单权限**：配置用户组可访问的菜单
-   **数据权限**：配置用户组可访问的数据资源
-   **启用/禁用**：控制用户组状态
-   **编辑/删除**：修改或删除用户组

## 菜单管理

管理系统的菜单结构，控制菜单的显示和访问权限。

### 查看菜单列表

1.  进入「菜单管理」页面
2.  页面以树形结构展示所有菜单，包括：
    -   **排序**：菜单显示顺序（支持拖拽调整）
    -   **菜单名称**：菜单显示名称
    -   **编码**：菜单唯一标识
    -   **路由路径**：菜单对应的路由地址
    -   **描述**：菜单说明
    -   **是否启用**：启用/禁用状态
    -   **操作**：管理按钮

### 查询菜单

1.  在页面顶部的查询区域：
    -   **菜单名称**：输入菜单名称搜索
    -   **编码**：输入编码搜索
2.  点击「查询」按钮
3.  点击「重置」按钮清空条件

### 新增菜单

1.  点击页面右上角「新增菜单」按钮
2.  或在已有菜单行点击「新增」按钮（添加子菜单）
3.  填写菜单信息：
    -   菜单名称
    -   编码
    -   路由路径
    -   描述
    -   父级菜单
    -   排序
    -   状态
4.  点击「创建」完成

### 编辑菜单

1.  在菜单列表中找到目标菜单
2.  点击「编辑」按钮
3.  修改菜单信息
4.  点击「确定」保存

### 启用/禁用菜单

1.  在菜单列表中找到目标菜单
2.  点击启用/禁用开关
3.  禁用的菜单将不会在系统导航中显示

### 删除菜单

1.  在菜单列表中找到目标菜单
2.  点击「删除」按钮
3.  确认删除操作

**注意：** 删除父菜单会同时删除所有子菜单。

### 调整菜单顺序

1.  点击菜单行前面的拖拽图标
2.  拖动到目标位置
3.  释放鼠标完成排序

## 常见问题

### Q1：角色和用户组有什么区别？

**角色**：主要用于定义用户的职能和权限范围，一个用户可以拥有多个角色。

**用户组**：用于将用户进行分组管理，方便批量分配权限，通常按部门、项目或其他业务维度划分。

### Q2：如何批量管理用户权限？

可以通过以下方式：

1.  将用户添加到用户组，为用户组分配权限
2.  为用户分配角色，用户自动继承角色的所有权限

### Q3：禁用角色后，已绑定的用户会怎样？

禁用角色后，该角色的权限不会生效，但用户仍然保留其他角色和用户组的权限。

### Q4：菜单权限和数据权限的区别？

**菜单权限**：控制用户可以看到和访问哪些系统菜单和页面。

**数据权限**：控制用户在特定功能中可以访问哪些具体的数据资源（如模型、智能体、应用等）。

### Q5：如何调整菜单显示顺序？

在菜单管理页面，通过拖拽菜单行前面的拖拽图标，可以调整菜单的显示顺序。

### Q6：删除角色/用户组前需要注意什么？

1.  确保没有用户绑定该角色/用户组
2.  确认该角色/用户组的权限配置不再需要
3.  建议先禁用而非直接删除，以免误操作

### Q7：权限配置不生效怎么办？

1.  检查角色/用户组状态是否为启用
2.  检查菜单和权限资源是否启用
3.  确认用户已正确绑定角色/用户组
4.  退出后重新登录系统

### Q8：编码字段可以修改吗？

编码是资源的唯一标识，系统自动生成，不建议修改。如需修改，请确保新编码的唯一性。
