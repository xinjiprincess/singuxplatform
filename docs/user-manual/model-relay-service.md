# 模型对外提供接口服务

> 更新：2026-10-04。账号积分与企业额度是两套范围；企业额度目前为预留配置，不承诺原子扣减或结算。

## 1\. 新增密钥

填写密钥名称，设置过期时间，空白即为永久有效。

## 2\. 权限配置

创建好密钥后需要进行权限配置，点击权限配置按钮，进入权限配置页面。 可设置**接口权限**、**系统模型**和**个人空间模型**的权限供接口调用。

> **注意：对外提供模型服务时，如果设置了提供服务的模型没有设置模型价格，则默认为免费，不会扣取积分**
> 
> 比如：权限配置中添加了平台提供的**系统模型**权限，因为系统模型都有设置模型价格，当调用分享的接口时，会扣取用户积分。如果个人空间模型没有设置模型价格，则默认为免费，不会扣取积分；设置模型价格会同样扣除用户积分，只是收益会转到个人账户。

选择要分享的模型，即可配置模型权限。

## 3\. 接口分享

配置完apikey之后，点击模型权限，选择要分享的模型后的**复制接口**按钮复制分享链接即可。

> **模型分享使用注意链接和标识要对应。**
