# 智能体执行环境部署

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

通用型依赖调度服务、执行容器、文件服务与预览网关，可在独立节点部署。

## 步骤

1. 固定镜像版本、架构、目录与 API。
2. 配置后端可达的内部地址，浏览器通过鉴权网关访问。
3. 系统沙箱配置填写节点、CPU、内存、并发与回收策略。
4. 测试普通账号创建、执行、文件读取、取消与释放。
5. 验证用户文件不可互访，以及断网、超时和重启恢复。

本地构建及健康不等于生产全链路验收。不直接复制开发环境 Docker socket 挂载。见 [沙箱](sandbox-management.md) 和 [运行恢复](../runtime-recovery-and-updates.md)。
