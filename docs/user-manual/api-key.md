# 获取API Key

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

API Key 的获取与配置分为两个部分：管理员授权与用户自行创建。

## 一、管理员授权接口调用权限

管理员可在后台为**用户组**统一授权，控制该组内用户可以调用的接口范围。

**操作路径**：系统管理 → 菜单权限 → 用户组管理 → 数据授权 → API权限

在此为用户组勾选允许调用的接口，该组内的所有用户将继承此权限。

> 此步骤普通用户无需关注。

## 二、用户创建 API Key

用户可自行创建 API Key，并为每个 Key 单独配置可调用的接口范围。

**操作路径**：左下角更多菜单 → API Key管理

1.  在 API Key管理页面中，点击**新增**创建新的 API Key
2.  为每个 API Key 配置**可调用的接口范围**，可灵活控制不同场景下的权限粒度
3.  创建完成后复制保存 API Key（请妥善保管，关闭后无法再次查看完整 Key）

## 注意事项

-   管理员可在后台控制是否允许用户获取 API Key
-   每个 API Key 的接口调用范围独立配置，建议按使用场景分别创建
-   API Key 相当于访问凭证，请妥善保管，避免泄露

## 公共参数

**请求头**

| 参数名 | 类型 | 必填 | 描述 | 示例值 |
| --- | --- | --- | --- | --- |
| Authorization | string | 是 | API Key | `Bearer ak-REPLACE_WITH_API_KEY` |
| 智能体平台-user-id | string | 否 | 智能体平台用户id，该参数管理员创建的API Key调用时有效，用于身份切换 | `1` |
| 智能体平台-user-uid | string | 否 | 智能体平台用户uid，该参数管理员创建的API Key调用时有效，用于身份切换 | `admin` |
| External-Username | string | 否 | 外部系统用户名，用于日志跟踪 | `张三` |
