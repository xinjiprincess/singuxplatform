# 订阅与积分

> 更新：2026-10-04。保留既有个人积分界面说明。企业套餐支付仅预留；微信和支付宝真实收款不在已交付范围。

订阅与积分管理模块是平台商业化体系核心模块，主要用于配置积分与货币兑换规则、管理订阅套餐、积分增购套餐，同时提供用户积分查询、业务订单管理能力，实现平台用户权益、积分计费、购买订单全流程管控。

* * *

## 一、基础配置

基础配置为订阅与积分体系全局总控模块，用于开关功能、设置兑换比例、配置新用户及登录积分赠送规则，是整个积分商业化体系的底层基础配置。

### 1.1 核心配置项

| 配置项 | 说明 |
| --- | --- |
| 订阅与积分功能开关 | 全局控制订阅、积分扣费、套餐购买整体功能启停，关闭后所有相关业务均失效 |
| 积分兑换比例 | 设定货币与积分换算比例，如 1元=1000积分，作为模型扣费、积分购套餐核算依据 |
| 换算描述 | 面向用户展示积分价值说明文案，用于前端页面提示 |
| 新用户注册赠送 | 可开启/关闭新用户注册送积分，支持设置赠送积分数量、积分有效期 |
| 每日登录赠送 | 可开启/关闭用户每日首次登录赠送积分，自定义每日赠送积分额度 |

### 1.2 配置注意事项

-   积分兑换比例修改后，仅对新调用、新订单生效，需提前做好业务告知；
-   积分赠送规则调整，不追溯已发放积分权益；
-   关闭总开关前，需确保在途订单、待结算业务处理完毕。
-   页面上的内容调整，需要点击下方的**保存**按钮后才会**生效**

## 二、基础订阅套餐

用于平台管理员维护各等级会员订阅套餐，可设置多等档位，可自定义套餐名称、价格、周期、权益、赠送积分及上架状态。

### 2.1 套餐列表字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 排序 | 否 | 可拖动排序按钮排序套餐 |
| 套餐名称 | ✅️ | 对外展示套餐名称 |
| 套餐描述 | ✅️ | 套餐定位、适用人群及权益说明 |
| 套餐价格（元） | ✅️ | 订阅售卖价格，免费版可设为0 |
| 套餐有效期 | ✅️ | 订阅周期，如月/季度/年/永久 |
| 每月赠送积分 | ✅️ | 订阅后每月固定赠送积分额度 |
| 热门标签 | 否 | 标记是否为推荐热门套餐 |
| 上架状态 | ✅️ | 控制套餐前端是否可见、可购买 |
| 开发者权限 | 否 | 关联用户权限组，绑定套餐对应功能权限 |

### 2.2 操作说明

-   **新增套餐**：填写完整配置项后保存并上架，套餐中如果需要调整资源配置等需要创建用户组，配置用户组资源权限（包括工作空间、智能体、技能、知识库......等等），然后添加不同用户组到**开发者权限**中； **新增套餐** 成功后可点击左下角用户头像上方的 **更多•••** 按钮打开 **我的订阅** 页面展示，用户可快速选择购买，开启**热门**的套餐会在套餐页面右上角突出显示；
    
-   **编辑套餐**：套餐添加后，所有可设置的资源均支持修改；
    
-   **下架套餐**：关闭上架状态，新用户无法购买，已订阅用户权益不受影响。
    

### 2.3 管理注意事项

套餐修改、下架避开用户高峰期，防止订单异常、权益错乱；各套餐积分赠送标准需与平台基础兑换规则统一。

## 三、积分增购套餐

管理员可配置多种积分充值套餐，用户直接付费购买获取积分，用于模型调用扣费消耗。

### 3.1 套餐配置字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 套餐名称 | ✅️ | 积分增购套餐名称 |
| 积分数量 | ✅️ | 购买后到账积分总额 |
| 有效期（月） | ✅️ | 套餐积分使用有效期限 |
| 售价（元） | ✅️ | 套餐实际售卖价格 |
| 上架状态 | ✅️ | 控制套餐前端是否展示可购买 |
| 备注 | 否 | 套餐活动说明、使用规则补充 |

### 3.2 操作说明

-   **新建套餐**：录入信息后上架对外售卖； 新建完成后可点击**积分面板**右侧的**增购**按钮显示套餐列表，用户可快速选择购买；
-   **编辑/删除**：可修改套餐参数或下架删除；
-   **状态开关**：快速控制套餐上下架。

### 3.3 管理注意事项

限时优惠套餐需合理设置有效期；套餐定价必须和平台积分兑换比例保持一致，避免套利。

## 四、用户积分查询

管理员可按**用户ID**、**用户名**筛选全平台用户积分数据，查看**积分构成**、**明细记录**，支持手动**增减积分**。

### 4.1 列表字段说明

| 字段 | 说明 |
| --- | --- |
| 用户ID/用户名/手机号 | 用户基础身份信息 |
| 总积分 | 用户当前可用剩余积分 |
| 套餐积分 | 会员订阅套餐赠送积分 |
| 增购积分 | 付费购买积分套餐到账积分 |
| 活动积分 | 平台各类活动发放积分 |
| 手动积分 | 管理员后台手动发放/扣减积分 |

### 4.2 功能操作

1.  **积分明细**：查看用户所有积分收支流水，可追溯来源与消耗去向；
2.  **积分发放**：管理员后台手动给用户加积分，用于补偿、奖励等场景；
3.  **积分扣减**：管理员合规扣减用户积分，用于违规处理、订单退款冲减。

### 4.3 管理注意事项

手动增减积分需留存操作备注，建议双人复核；所有积分变动自动留痕，支持审计溯源。

## 五、业务订单查询

集中管理用户订阅套餐、积分增购所有支付订单，多条件筛选、查看订单详情与状态。

### 5.1 订单列表字段

| 字段 | 说明 |
| --- | --- |
| 订单ID/用户ID | 订单编号及所属用户标识 |
| 业务类型 | 区分：会员订阅、积分购买 |
| 描述 | 对应购买套餐名称说明 |
| 金额 | 订单实际支付金额 |
| 订单状态 | 待支付、已支付、已取消 |
| 开始时间/修改时间 | 订单创建时间、状态变更时间 |

### 5.2 功能操作

-   **组合筛选**：支持订单ID、用户ID、业务类型、订单状态、时间范围筛选；
-   **重置条件**：一键清空所有筛选条件，恢复默认列表；
-   **分页浏览**：支持自定义每页展示条数，分页查看订单数据。

### 5.3 管理注意事项

需定期核对支付渠道与平台订单状态一致性；订单数据长期留存，用于财务对账与后台审计。

* * *

## 六、通用权限与管理注意事项

1.  仅平台管理员拥有基础配置、套餐新增编辑、手动增减积分、查看全部订单权限；
2.  普通用户仅可查看个人积分、个人订单，无后台配置权限；
3.  所有积分变动、订单生成均自动记录日志，数据可追溯、可审计；
4.  用户支付成功后，订单状态、积分到账自动同步生效。
