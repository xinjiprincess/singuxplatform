# 数据表功能介绍

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

> 数据表是 智能体平台 提供的**结构化数据存储与调用能力**，用于承载业务数据（如客户信息、商品库存、订单记录等）。可将数据表作为知识文本接入智能体，或添加到工作流中，实现数据的统一管理与智能化调用。本功能可以理解为智能体的「Excel 表格」：既有表头（字段）约束数据结构，又有行记录承载业务数据。

## 一、功能概览

数据表功能围绕「定义结构 → 填充数据 → 应用数据」三个环节提供完整能力：

| 环节 | 能力 | 说明 |
| --- | --- | --- |
| 定义结构 | 创建数据表 / 调整表结构 | 定义表名、描述与字段（含字段类型、约束、默认值） |
| 填充数据 | 自动导入 / 手动新增 | 支持 Excel 一键导入与逐条手动录入 |
| 应用数据 | 智能体调用 / 工作流引用 | 作为知识文本接入智能体，或加入工作流流程 |

其中**自动导入**是官方推荐的首选数据填充方式：准备好 Excel 文件后，表结构与表数据可在导入时一次性自动创建完成，无需手动设计字段。

## 二、创建数据表

创建数据表是使用数据表功能的第一步，操作路径如下：

1.  进入**工作空间**；
2.  打开**组件资源**；
3.  选择**数据表**分类；
4.  点击**添加数据表**，进入创建入口；
5.  填写数据表的**名称**和**描述**，点击**确定**完成创建。 创建完成后，每张数据表都会携带系统默认字段，方便用户使用：

> 数据表初始不包含任何数据，需要先导入或定义表结构（字段），再填充数据。

## 三、自动导入表结构和表数据（推荐）

自动导入是**最推荐的建表方式**，尤其适用于已有 Excel 数据需要快速迁移的场景。与传统方式相比，它省去了手动设计字段的步骤，表结构与表数据一次成型。

### 3.1 适用前提

使用自动导入需满足以下条件：

-   准备好一份 **Excel 表格文件**；
-   表格的**表头位于第一行**；
-   表格中**不能存在合并单元格**。

### 3.2 导入原理

系统会自动识别 Excel 中的表头，并将其**转换为英文字段名**，作为数据表的字段定义；Excel 中的每一行数据将同步转换为数据表的记录。

### 3.3 操作步骤

1.  进入数据表的**表数据**页面；
2.  点击**导入数据**；
3.  选择已准备好的 Excel 文件。

导入完成后，**表数据和字段名会在导入时自动创建完成**，无需再手动调整表结构（如需微调，可参考下一章「调整表结构」）。

## 四、调整表结构

当需要自定义字段、或对自动导入生成的表结构进行微调时，可通过调整表结构完成。刚刚创建的数据表没有任何数据，在添加数据之前需要先给数据表添加字段——**字段可以理解为 Excel 的表头**。

### 4.1 字段名

字段名相当于 Excel 的列标题，如 `name`、`age`、`gender` 等，输入的值必须符合系统要求，**字段名只能包含字母、数字、下划线，且必须以字母开头**。

### 4.2 字段详细描述

用于描述字段的具体用途，帮助后续使用者（包括智能体）理解该字段承载的内容，例如「用户的登录账号」。

### 4.3 字段类型

系统支持以下四种字段类型：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| **String（字符串）** | 表示文本数据，由字符序列组成，可包含字母、数字、符号等。提供**短文本**和**长文本**两种长度可选：名字等简短信息选择短文本；自我介绍等长篇幅内容选择长文本 | `hello`、`world` |
| **Integer（整数）** | 表示没有小数部分的数值，可正可负，用于精确的整数值运算 | `1`、`-5`、`100` |
| **Number（数字）** | 宽泛的数值概念，既包含整数也包含浮点数（带小数的数），涵盖整数和小数的数值类型 | `3.14`、`2.5` |
| **Boolean（布尔值）** | 仅有两个取值 `true`（真）和 `false`（假），主要用于逻辑判断（如条件语句、循环语句中的条件判断） | `true`、`false` |

### 4.4 字段约束

在字段定义中可配置以下约束项：

-   **是否必须**：指定该字段在插入数据时是否必须包含值。例如用户表中的「用户名」通常是必须的，而「邮箱」可能允许为空。
-   **是否唯一**：确保该字段的所有值在表中都是唯一的，不允许重复，常用于标识记录的唯一性。例如「用户ID」必须唯一防止混淆；身份证号或邮箱字段也可设为唯一，避免重复注册。
-   **是否启用**：控制该字段是否被使用。例如用户表中的 `is_active` 字段设为 `false` 时用户无法登录，但数据仍保留；商品表中的 `is_enabled` 可临时下架商品而不删除商品信息。
-   **默认值**：当插入记录时未显式为该字段赋值，则自动使用预设的默认值。

### 4.5 保存与查看

字段配置完成后点击**保存**， 切换到**表数据**页面即可看到刚刚创建的字段名。

## 五、手动新增表数据

调整完表结构之后，即可往数据表中手动添加数据：

-   逐条录入记录，填写各字段的值；
-   适用于数据量较小、或需要单独补充个别记录的场景。

> **提示**：数据量较大时，建议优先使用第三章介绍的自动导入方式，效率更高且能同步创建字段。

## 六、清空表中所有数据

当需要清除数据表中的全部数据时，可使用清空功能。**需要注意：表数据非常重要，且一旦删除无法恢复，删除数据前一定要慎重确认数据是否要清空。**

清空操作包含二次确认机制：

1.  点击**清除所有数据**；
2.  系统弹出清除确认提示框；
3.  **输入表名**后方可执行清除。

> **⚠️ 重要提示**：清空操作不可回退、无法恢复，请务必在确认数据无需保留后再执行。

## 七、使用数据表

数据表创建并填充数据后，可通过以下两种方式在业务中应用：

### 7.1 添加到智能体

数据表可以在智能体中**作为知识文本**添加到智能体中，供智能体调用，使智能体在对话中能够检索和使用表中的结构化业务数据。

### 7.2 添加到工作流

数据表也可以**添加到工作流**中，作为流程中的数据来源或数据存储，参与自动化业务处理。

## 八、总结

数据表功能为 智能体平台 提供了**结构化业务数据的管理与调用能力**：

-   **创建简单**：通过组件库几步即可创建数据表；
-   **导入高效**：自动导入支持 Excel 一键建表，表结构与数据同步生成，为官方推荐方式；
-   **结构灵活**：字段类型、约束与默认值配置完善，满足多样化数据模型；
-   **应用广泛**：可作为知识文本接入智能体，也可加入工作流参与自动化处理。

将业务数据沉淀到数据表中，即可让智能体「读懂并调用」您的业务数据，实现数据驱动的人机协同。
