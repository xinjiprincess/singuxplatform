# 任务中心

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

## 1\. 概述

### 1.1 什么是任务中心?

任务中心是一个强大的定时任务管理系统,帮助您自动化执行重复性工作。通过设置定时周期和任务内容,系统会自动在指定时间执行任务,提高工作效率,减少人工操作。

### 1.2 核心功能特性

-   **⏰ 灵活的定时配置** - 支持按小时、天、周等多种周期设置任务执行时间
-   **🤖 智能体任务支持** - 可配置AI助手执行各类智能化任务
-   **⚙️ 工作流任务支持** - 支持配置自动化工作流,实现复杂业务流程的自动化
-   **📊 完整的执行记录** - 追踪每次任务执行情况,便于问题排查
-   **🔍 便捷的查询筛选** - 支持按类型、名称快速查找目标任务

### 1.3 任务对象类型

任务中心支持两种主要的任务对象类型:

#### 🤖 智能体

智能体是具备AI能力的助手,可以理解和执行自然语言指令,例如:

-   数据查询和分析
-   文档处理和总结
-   邮件发送和通知
-   信息收集和报告生成

#### ⚙️ 工作流

工作流是预定义的自动化流程,可以按照设定的步骤序列执行操作,例如:

-   多步骤数据处理流程
-   跨系统集成操作
-   批量任务处理
-   定期报告生成和分发

> **💡 选择建议**
> 
> -   简单的、需要灵活理解的任务 → 使用智能体
> -   复杂的、需要固定步骤的任务 → 使用工作流

## 3\. 创建任务

### 3.1 创建任务步骤

#### 步骤 1: 点击创建任务按钮

在任务中心主界面右上角,点击蓝色的"创建任务"按钮,系统将弹出创建任务对话框。

#### 步骤 2: 设置定时周期 ⭐

**定时周期** (必填项)

选择任务执行的频率和时间:

-   第一个下拉框: 选择周期类型(如"每小时"、"每天"等)
-   第二个下拉框: 选择具体的执行时间点(如"00分"表示整点执行)

#### 步骤 3: 填写任务名称 ⭐

**任务名称** (必填项)

输入一个易于识别的任务名称,最多100个字符。例如: "天气预报"、"日报生成"等。

#### 步骤 4: 选择任务对象 ⭐

**任务对象** (必填项)

选择执行该任务的对象。系统支持两种类型的任务对象:

**🤖 智能体类型**

-   选择合适的AI智能体执行任务
-   系统会显示助手的名称和简介
-   例如: "智能体平台助手 - 能帮你查资料看文档的AI综合助理"

**⚙️ 工作流类型**

-   选择已创建的工作流
-   工作流会按照预定义的步骤序列执行
-   适合复杂、多步骤的业务流程

点击"+"按钮可以添加新的任务对象。

> **💡 如何选择**
> 
> -   需要灵活理解和执行自然语言指令 → 选择智能体
> -   需要按照固定步骤执行 → 选择工作流

#### 步骤 5: 设置会话保持 ⭐

**保持会话** (必填项)

选择任务执行时是否保持会话状态:

-   ✅ **是** - 任务执行期间会话持续,适合需要上下文的任务
-   ❌ **否** - 任务完成后结束会话,每次执行都是独立会话

#### 步骤 6: 输入任务内容 ⭐

**任务内容** (必填项)

详细描述任务要执行的具体操作,最多10000个字符。例如: "查询成都此时天气,发送到我的邮箱 [fengfei@智能体平台.com](mailto:fengfei@智能体平台.com)"

#### 步骤 7: 保存任务

点击"确定"按钮保存任务配置,或点击"取消"按钮放弃创建。保存后任务将按照设定的周期自动执行。

> **⚠️ 注意事项**
> 
> -   所有带红色星号(\*)的字段都是必填项
> -   任务内容应清晰明确,便于AI助手准确执行
> -   定时周期设置后,任务将按计划自动执行,请确保配置正确

## 4\. 任务管理

### 4.1 任务操作功能

在任务列表的"操作"列,提供以下功能按钮:

| 操作 | 说明 |
| --- | --- |
| **手动执行** | 立即触发任务执行,不受定时周期限制 |
| **停用** | 暂停任务的自动执行,停用后不会按计划运行 |
| **更多操作 (...)** | 点击省略号展开扩展操作菜单 |

### 4.2 扩展操作菜单

点击操作列中的"..."按钮,将弹出更多操作选项:

#### 📋 执行记录

查看该任务的历史执行记录,包括:

-   执行时间
-   执行结果
-   错误信息(如果有)

#### ✏️ 编辑

修改任务的配置参数,包括:

-   定时周期
-   任务名称
-   任务对象
-   会话保持设置
-   任务内容

#### 🗑️ 删除

永久删除该任务及其所有执行记录(**此操作不可恢复**)

> **💡 操作技巧**
> 
> -   使用"手动执行"可以立即测试任务配置是否正确
> -   查看"执行记录"有助于排查任务执行失败的原因
> -   临时不需要某个任务时,可以使用"停用"而非删除,方便后续重新启用

## 5\. 查询筛选

### 5.1 筛选功能

任务中心提供强大的查询筛选功能,帮助您快速找到目标任务:

#### 📂 任务类型筛选

通过下拉框选择特定任务类型进行筛选

> **💡 筛选提示**
> 
> -   任务类型和任务名称可以组合使用,实现更精确的筛选
> -   任务名称支持模糊匹配,输入部分关键字即可
> -   筛选后可以点击"重置"快速恢复到显示全部任务的状态

## 6\. 任务状态

### 6.1 状态类型说明

任务中心中的任务可能处于以下几种状态:

| 状态 | 说明 |
| --- | --- |
| 🟢 **执行成功,待下次执行** | 任务上一次执行成功,正在等待下一次执行时间 |
| 🟡 **执行失败,待下次执行** | 任务上一次执行失败,但会在下次计划时间重试 |
| 🔴 **已停用** | 任务已被用户手动停用,不会自动执行 |
| 🔵 **执行中** | 任务正在执行中 |

## 7\. 常见问题

### Q1: 如何修改已创建的任务?

点击任务列表中对应任务的"..."按钮,在弹出菜单中选择"编辑",即可修改任务的各项配置。修改后记得点击"确定"保存更改。

### Q2: 任务执行失败怎么办?

首先通过"执行记录"查看失败原因,常见原因包括:

-   任务内容描述不清晰
-   任务对象配置错误
-   网络连接问题

修复问题后,可以使用"手动执行"功能重新测试任务。

### Q3: 如何临时暂停某个任务?

点击任务操作列中的"停用"按钮即可暂停任务。停用后任务不会按计划执行,但任务配置和执行记录都会保留。需要恢复时,点击"启用"即可重新激活任务。

### Q4: 智能体和工作流有什么区别?

**智能体**和**工作流**是两种不同的任务对象类型:

| 特性 | 智能体 | 工作流 |
| --- | --- | --- |
| **执行方式** | 理解自然语言指令,灵活执行 | 按照预定义步骤序列执行 |
| **适用场景** | 数据查询、文档处理、邮件发送等 | 多步骤流程、跨系统集成、批量处理 |
| **灵活性** | 高,可以理解复杂的自然语言指令 | 中,需要预先设计流程 |
| **可靠性** | 依赖AI理解能力 | 严格按照步骤执行,结果可预测 |
| **配置难度** | 简单,只需描述任务内容 | 较高,需要设计工作流步骤 |

**选择建议:**

-   需要AI理解和处理 → 使用智能体
-   需要精确的步骤执行 → 使用工作流

### Q5: 可以设置多个执行时间点吗?

目前一个任务只能设置一个定时周期。如果需要在多个时间点执行,建议创建多个任务,分别配置不同的执行时间。

### Q6: "保持会话"选项应该选择是还是否?

这取决于您的任务特点:

-   **选择"是"**: 适合需要上下文记忆的任务,如连续对话、多步骤操作等
-   **选择"否"**: 适合独立性任务,每次执行都是全新的开始

> **⚠️ 注意**: 工作流类型的任务通常建议选择"否",因为工作流本身已经包含了完整的步骤定义。

### Q7: 删除任务后能恢复吗?

删除操作是不可逆的,任务及其所有执行记录都会被永久删除。建议在删除前确认该任务确实不再需要。如果只是暂时不需要,建议使用"停用"功能。

### Q8: 如何查看任务的详细执行记录?

点击任务操作列中的"..."按钮,选择"执行记录",系统将显示该任务的所有历史执行情况,包括执行时间、执行状态、执行结果、错误信息等详细信息。

### Q9: 任务列表显示不全怎么办?

使用页面底部的分页导航可以查看更多任务。也可以调整"每页显示条数"来增加单页显示的任务数量。如果任务很多,建议使用筛选功能快速定位目标任务。

### Q10: 工作流任务失败如何排查?

工作流任务执行失败时,可以通过以下方式排查:

1.  查看"执行记录",定位失败的具体步骤
2.  检查工作流配置是否正确
3.  验证工作流中的每个节点是否正常工作
4.  检查系统集成的连接状态
5.  使用"手动执行"重新测试工作流

### Q11: 智能体任务执行结果不符合预期怎么办?

智能体任务依赖对自然语言的理解,如果结果不符合预期:

1.  检查任务内容描述是否清晰明确
2.  提供更详细的指令和示例
3.  考虑将复杂任务拆分为多个简单任务
4.  查看"执行记录"了解智能体的执行过程
5.  必要时考虑改用工作流以获得更精确的控制

## 8\. 使用技巧

### 8.1 最佳实践

#### 📝 任务命名规范

使用清晰、描述性的任务名称,如"每日天气报告发送给团队",便于后续识别和管理。

#### ⚡ 任务内容明确

在任务内容中提供详细的执行指令,包括具体要求、输出格式、目标地址等。

#### 🧪 测试后再启用

创建任务后先使用"手动执行"测试,确认无误后再让任务按周期自动执行。

#### 📊 定期检查执行记录

定期查看任务执行记录,及时发现和解决问题,确保任务正常运行。

#### 🏷️ 合理使用任务类型

根据业务需求合理设置任务类型,便于后续筛选和统计。

#### 🎯 智能体任务优化

-   使用清晰、具体的自然语言描述任务
-   提供上下文信息和期望的输出格式
-   对于复杂任务,考虑分步描述或使用示例

#### ⚙️ 工作流任务优化

-   设计简洁明确的工作流步骤
-   添加适当的错误处理和重试机制
-   为关键步骤添加日志记录
-   定期测试工作流的完整性

### 8.2 任务对象选择指南

根据不同场景选择合适的任务对象:

| 场景 | 推荐对象 | 理由 |
| --- | --- | --- |
| 定期发送邮件报告 | 🤖 智能体 | 需要生成报告内容的灵活性 |
| 数据同步和备份 | ⚙️ 工作流 | 需要可靠的步骤执行 |
| 定期数据查询和分析 | 🤖 智能体 | 需要理解查询需求 |
| 批量文件处理 | ⚙️ 工作流 | 固定的处理流程 |
| 定期系统监控 | 🤖 智能体 | 需要智能判断和通知 |
| 跨系统数据集成 | ⚙️ 工作流 | 需要精确的集成步骤 |
| 定期文档生成 | 🤖 智能体 | 内容生成需要灵活性 |
| 定期数据清洗 | ⚙️ 工作流 | 标准化的处理流程 |
