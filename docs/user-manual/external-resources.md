# 外部资源接入与管理

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

外部生态门户不是内置服务。原厂账号、套餐价格、统一积分和支付不适用于当前平台。

## 本项目入口

- 模型：系统及空间模型管理，配置实际协议、标识、地址、密钥。
- 技能：审核指令、脚本、依赖和许可证再导入。
- 工具：插件与 MCP，按需配置第三方服务及权限。
- 模板：使用当前可访问的空间资源，外部市场需独立授权。
- 日志：通过 requestId/tid 查询空间与系统记录。

明确能力需求，核对来源、费用、权限，最小测试后挂载。外部账号积分不自动与本地互通。
