# MCP接入与开放

> 更新：2026-10-04。本地完成过只读工具代理调用；生产部署、全部工具兼容与运行时隔离仍须验收。

MCP（Model Context Protocol，模型上下文协议）是一种开放标准协议，旨在为大型语言模型（LLM）与外部数据源、工具之间建立标准化连接，解决传统AI集成中的碎片化和安全性问题。

## 接入MCP

点击工作空间→MCP管理→创建MCP服务 输入服务`名称`、`描述`，选择`安装方式`，将MCP的配置代码填写到`MCP服务配置`代码框中 点击右上角的`保存并部署`即配置完成，可以使用此MCP服务

## 测试MCP功能

点击`工具`，点击试运行

## 使用MCP

可以直接在智能体中调用MCP

## 开放MCP服务

我们可以将我们制作的`插件`、`工作流`、`知识库`、`数据表`等等功能封装成MCP服务，提供给其他用户使用，就和我们接入别人的MCP服务一样 可以在MCP卡片中`导出服务`，这种方便快捷的分享方式也避免了我们暴露内部的功能组件
