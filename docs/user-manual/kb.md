# RAG知识库与知识图谱功能介绍

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

* * *

## 一、功能概述

知识库是用于系统化存储、管理和共享组织或个人知识的基础设施，可理解为智能体的"大脑数据库"。其价值体现在三个层面：

-   **划定知识边界**：定义智能体的知识范围与专业深度，使其回答始终限定在既定领域内；
-   **支撑推理学习**：为智能体的动态学习与复杂推理提供内容基础；
-   **降低维护成本**：知识内容集中管理与复用，减少重复开发与维护投入。

无论是客服、教育、医疗还是企业内部协作等场景，知识库的质量直接决定智能体的实用性与可靠性。

**RAG（Retrieval-Augmented Generation，检索增强生成）** 是该能力的核心技术框架，它将信息检索与文本生成相结合：智能体在回答前，先从知识库中检索与问题相关的内容片段，再基于检索结果组织作答，从而显著降低凭空生成（幻觉）的风险。

在知识库基础能力之上，**知识图谱**进一步将文档中的知识提取为实体与关系的网络结构，支持跨文档关联与关系推理，二者共同构成 智能体平台 完整的知识管理方案。

* * *

## 二、核心概念：知识库与知识图谱

| 维度 | 知识库（RAG） | 知识图谱（GraphRAG） |
| --- | --- | --- |
| 数据组织 | 文档切分、向量化存储 | 实体、关系、三元组构成的网络 |
| 检索方式 | 语义相似度匹配 | 沿关系链进行结构化查询 |
| 擅长场景 | "是什么"类事实问答 | "谁和谁什么关系"类关联问答 |
| 回答依据 | 检索到的相关文本片段 | 可追溯的关系路径 |
| 类比 | 可检索的资料库 | 可遍历的关系地图 |

两者的核心区别在于数据组织方式：**知识库以文本碎片为单位存储，知识图谱以实体与关系为基本单元**。二者并非替代关系，而是互补关系——简单事实查询依赖知识库的检索效率，复杂关联问题交由图谱的推理能力，组合使用可获得最佳效果。

## 三、创建知识库

**入口**：登录 智能体平台 平台后，依次进入「工作空间 → 组件资源 → 知识库 → 创建知识库 」。 创建知识库需配置以下信息：

| 配置项 | 说明 |
| --- | --- |
| 知识库名称 | 用于标识与检索知识库 |
| 知识库简介 | 描述知识库的内容范围与用途 |
| 向量模型 | 选择用于文档向量化的模型 |
| 提取方式 | 默认解析方式，或选择**自定义工作流** |

> **自定义工作流**：支持自定义数据解析的类型与方式，适用于对解析过程有特殊要求的场景

## 四、添加知识库内容

知识库内容的添加支持两种方式：

### 4.1 本地文档

直接上传本地知识文件。上传后需选择**分段与清洗方式**，确认后开始数据处理流程。

-   本地文档：直接上传知识文件
-   上传后选择分段与清洗方式
-   最后确认就可以开始**数据处理**了

### 4.2 自定义内容

将内容直接复制到文档内容栏中，后续处理流程与本地文档一致。适用于内容较短、格式简单或尚未整理为文件的场景。

## 五、数据处理与 QA 问答

### 5.1 数据处理

文档经向量模型解析后，生成**向量化文档**并展示在「文档」内容栏中。点击文档名称可查看文档内容，用于确认解析结果是否符合预期。

### 5.2 QA 问答

向量模型解析完成后，系统会同时生成 **QA 问答**内容。此外，可手动添加问答内容以提升知识库的准确性，适用于两类场景：

1.  调用知识库时**未能匹配到准确答案**；
2.  需要针对特定问题提供**专门回答**。

QA 问答的添加支持两种模式：

-   **手动添加**：逐条录入问题与答案；
-   **批量导入**：先下载 Excel 模板，按固定格式填写问题与答案后上传文件，一次性完成多条导入。

## 六、知识图谱（知识库增强能力）

### 6.1 功能概念

**什么是知识图谱？**

想象一下，如果你把所有朋友的名字写在纸上，再把"谁认识谁""谁是谁的同事""谁是谁的老板"用一条条线连起来，你就得到了一张**人际关系网**。

**知识图谱（Knowledge Graph）就是这么一张"网"**——只不过它连接的不是人，而是**知识**：把文档里分散的知识点提取出来，作为一个个**节点**，再用**关系**把它们串成一张有结构、可追溯的网络。

它和我们熟悉的"家谱""地铁线路图"是同一个思路：**重要的不是单个信息，而是信息之间的关联**。

> 📌 最经典的例子：搜索引擎早就用上了知识图谱。你搜"成都"，结果里除了网页，还会直接出现"四川省会""人口2100万""大熊猫基地所在地"等结构化信息——这就是图谱在起作用。 知识图谱会把知识库中**所有文档**的内容都做关联，并非只关联一个文档的内容。

### 6.2 能力特征

-   **跨文档关联**：知识图谱会关联知识库内**全部文档**的内容，而非局限于单个文档；
-   **关系检索**：支持基于实体与关系的结构化查询，可回答需要多步关联推理的问题；
-   **GraphRAG 增强问答**：将图谱关系信息融入检索增强生成流程，提升复杂问题的回答准确性。

### 6.3 创建知识图谱

-   **进入**：在知识库内切换至「知识图谱」标签页；
-   **创建**：点击「创建」按钮，开始构建知识图谱；
-   **等待构建**：系统从文档中抽取实体与关系并完成图谱构建；
-   **查看**：点击文档名称进入图谱展示页面，以节点连线形式查看实体及其关联；
-   **交互**：点击任意节点，查看该实体的相关实体与原文溯源信息。

## 七、测试命中（检索效果验证）

知识库完成创建并导入文档后，其检索效果需通过实际验证方可确认。智能体能否准确检索到预期依据的内容片段，是决定知识库实用性与可靠性的关键。

**测试命中**功能用于验证上述效果：用户可输入任意查询语句对知识库执行检索测试，直观查看**命中内容、排序结果与匹配评分**，从而在正式发布使用前及时发现并定位问题。

> 与知识图谱的协同：测试命中用于**验证**知识库的检索效果，知识图谱用于**扩展**知识库的关系能力，二者结合可充分发挥知识库的整体价值。

## 八、知识库的使用

知识库创建并完善后，可在以下场景中引用：

-   **在智能体中引用知识库**：为智能体配置知识库，使其在回答时基于库内知识进行检索增强生成；

-   **在工作流中引用知识库**：在工作流编排中调用知识库能力，实现流程化的知识查询与处理。

## 九、维护与删除

-   **删除文档**：知识库可存入多个文档，每个文档支持单独删除；
-   **删除知识库**：返回组件库，点击知识库卡片右下角「菜单」按钮，在下拉列表中选择「删除」。 返回组件库，点击找到创建好的知识库卡片，点击右下角的“菜单”按钮，在弹出的下拉列表中点击“删除”选项

> ⚠️ **重要提示**：删除文档与删除知识库的操作**无法回退和撤销**，请谨慎操作。

## 十、总结

| 能力 | 定位 | 核心价值 |
| --- | --- | --- |
| 知识库（RAG） | 基础能力 | 存储与检索知识，支撑事实类问答 |
| 知识图谱 | 增强能力 | 关系化组织知识，支撑关联推理 |
| 测试命中 | 质量保障 | 上线前验证检索效果，确保回答可靠 |

智能体平台 以知识库为基石，以知识图谱为扩展，以测试命中为保障，构成完整的知识管理闭环：**创建知识库 → 添加内容 → 生成知识图谱 → 验证检索效果 → 在智能体与工作流中引用**。通过该体系，智能体不仅"记得住"知识，更能"理得清"知识之间的关系，实现更高水平的回答质量与可靠性。
