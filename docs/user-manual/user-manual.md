# 平台概览

> 更新：2026-10-04。本章为功能与操作参考，实际菜单取决于服务器授权和环境配置。界面存在不表示生产能力已验收，环境边界以项目操作指南为准。

Singu X 用于开发和使用智能体。用户在工作空间维护模型、插件、工作流、知识库、数据表和技能，创建智能体并按权限发布、分享和集成应用。

## 访问与支持

主入口为 https://www.ciyuancenter.cc ，登录路径 /login。使用管理员分配的用户名密码，支持渠道为当前平台运营方或空间管理员。

## 使用范围

线上继续单租户。模型、MCP、沙箱、文件及发布取决于部署和授权，多企业隔离与企业支付不作为已开通承诺。

先阅读 [项目操作指南](project-guide.md)，再阅读功能章节。
