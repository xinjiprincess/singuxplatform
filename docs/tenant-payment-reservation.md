# 企业支付预留

2026-09-26 用户确认：仅预留微信支付和支付宝，不实现真实支付。

## 当前边界

- 支付渠道标识预定为 `WECHAT_PAY`、`ALIPAY`。
- 两个渠道均为 `NOT_CONFIGURED`；企业在线订购、收款、退款、支付回调均未接通，不生成假支付成功状态。
- 不添加真实商户号、私钥或回调密钥，不请求第三方支付接口，不新增可点击的付款入口。
- 平台管理员现有套餐调整是人工配置，不代表已收款，也不生成付款凭证。
- 现有用户/智能体的支付模块不等于企业套餐支付；本批不改变原模块行为。

## 后续接口约定（尚未实现）

企业订单应由后端读取不可变套餐版本计算人民币分金额，禁止采用客户端报价。订单绑定企业、订购人、套餐版本、支付渠道、商户订单号及幂等键。

预留创建订单、查询订单、支付通知和退款能力。接入之前所有渠道应保持不可用；验签、金额/商户/订单核对、回调幂等、事务化开通及审计完成后才能开放。禁止以前端支付跳转结果作为开通依据。

商户配置仅在服务端保管，公开配置只返回渠道可用性。真实接入需另行提供商户资质、明确退款和开票规则并完成沙箱验收。
