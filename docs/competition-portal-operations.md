# 专用平台本地使用说明

本轮仅在本地 Docker 验证，未发布 `www.ciyuancenter.cc`。当前版本 `1.1.10-20260929-background`。

## 入口

- 比赛：`http://127.0.0.1:18093/zhichuangbei/login`
- 官网流程：`http://127.0.0.1:18093/login`
- 专用平台管理：`http://127.0.0.1:18093/platform/portals`
- 租户、成员与额度管理：`http://127.0.0.1:18093/platform/tenants`

本地管理员用户名为 `admin`，口令使用本轮用户指定值，不在文档或镜像中保存明文。官网登录后选择“Singu X平台”再进入管理；比赛登录不需要企业选择。

## 管理步骤

官网与比赛可独立设置登录及工作台背景：进入“专用平台”，官网点“官网背景”，比赛点对应“编辑”。支持站内路径、预览及清空恢复；图片持久化和服务器增量更新见 `server-incremental-update.md`。

1. 在官网管理会话进入“专用平台”，编辑智创杯入口。
2. 可修改名称、副标题、站内 Logo/favicon 路径、主题色、启停、开始与结束时间；时间使用带时区的 ISO 8601，如 `2026-10-01T00:00:00+08:00`，留空表示无该边界。
3. 每次填写变更原因。其他管理员已修改时须刷新后重新编辑，不能静默覆盖；已建立入口不可改绑租户。
4. 在租户管理选择本地比赛租户（ID 4）配置成员资格和额度。已有账号通过平台管理员添加成员，不自动将所有官网用户加入比赛。
5. 新比赛租户不复制官网智能体或作品。先建立比赛资源、配置模型与默认智能体，再验证业务使用；没有默认智能体时首页为空属于正常状态。

新增学校/企业临时入口时，先准备独立且初始化完成的租户，再创建新的 slug 绑定它。不得使用保留路由名称；未知、停用、到期入口不会回退到官网企业。配置多个入口仍共用同一应用服务，不自动产生多套 Java 服务。

## 验证与边界

本地验证执行 `deploy/test-local-portal.ps1`，按提示输入管理员口令。该脚本会短暂禁用比赛入口并在 finally 中恢复，用于本地测试，禁止直接用于正在举行的生产比赛。

原始权限模板初始化、镜像命令、错误排查分别见 `competition-portal-debug.md` 和 `local-docker-build.md`。本轮没有完成公开报名页面、分享/下载/WebSocket 全路径审计、跨团队资源隔离压测或 MCP/沙箱/网页应用全链路验收，不应直接作为正式比赛上线验收。

同域不同路径不是浏览器安全隔离，不可信网页预览仍须独立 origin。比赛 Logo 暂用平台现有图片，可在管理页替换为经授权的赛事素材路径。
