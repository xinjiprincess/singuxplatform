## 范围与验证

- 知识库指定的问答模型优先于租户默认模型；异步任务使用传入的租户上下文，不回退到硬编码模型 1。未配置模型或跨租户资源会在请求模型之前失败。

## 导入镜像

在解压目录校验 `SHA256SUMS` 后执行：

```sh
docker load -i images.tar
docker image inspect singux/backend:1.1.10-20261008-service-recovery-r1
```

这一步仅导入镜像，不重建容器，不影响数据卷。

当前包标记 `productionApproved=false`。不能使用上一次知识库删除补丁的更新器安装本包：上次更新器固定了更早的生产基线。正式切换前需要核验当前运行 JAR、保留 Compose/环境配置、备份数据库和数据卷，并针对本次基线完成更新及回退验证。不要执行 `docker compose down -v`、清理数据卷或覆盖整套生产 Compose。
